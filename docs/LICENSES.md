## Runtime dependencies

None. `package.json` has no `dependencies`; Vite, Vitest, Playwright, ajv, ESLint and `ts-fsrs` are **development** dependencies only. `ts-fsrs` (MIT) is used only to generate reference test vectors; the scheduler in `src/engine/srs.js` is a port written by reading the library's source, and the port version (3.5.7) is recorded in [DECISIONS.md](DECISIONS.md).

## Asset manifest and audit

`content/assets.manifest.json` lists every third-party or recorded asset. It is empty in this release. `scripts/license-audit.mjs` (run in every build) fails on:

* runtime dependencies, IndexedDB, Workbox, or remote origins in shipped source;
* manifest entries without name, path, origin, creator, or an allowed licence (CC0-1.0, CC-BY-4.0, MIT, owner-produced, generated-original);
* media files in `dist/` (audio, fonts, images other than the generated icons) with no manifest entry;
* content marked `human_reviewed` without a named reviewer and date.

A negative fixture (`tests/fixtures/bad-asset-manifest.json`, marked as not shipped) proves the audit fails for bad input (`tests/unit/license-audit.test.js`).
